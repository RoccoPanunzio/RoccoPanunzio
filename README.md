## About

I have worked on automated assembly lines and test benches for the automotive industry since 2018. I write the machine software, and I size and commission the vision systems and robot cells that go with it. A good part of that happens on the customer's floor, during FAT and SAT.

## What I work on

- **Industrial automation:** PLC and HMI software for assembly lines and test benches
- **Machine vision:** inspection, identification and 3D guidance
- **Robotics:** robotic cells for handling and bin picking
- **Systems integration:** MES, databases and traceability
- **Software tools:** C# and .NET tooling around the machines

## Side projects

Alongside my day job, I build software tools for the same industry in C# and .NET. Most are private for now.

| Project | What it does |
|---|---|
| **OPC UA bench server** | Simulated Siemens S7-1500 OPC UA server for testing without hardware |
| **Structured Text host** | .NET host that reads, checks and runs IEC 61131-3 Structured Text, with a browser editor |
| **SQL Server bench** | Local SQL Server test environment with a management panel |

## Selected work

- **Dynamic EOL test bench for electric motors.** Full software on S7-1500 and WinCC Unified. Two synchronised dynamometer benches, road-load profiling, a TCP/IP link to LabVIEW and test reports written to SQL.
- **11 stations of a 72-station hybrid transmission line.** Software and commissioning inside a 13-programmer team: tightening spindles, servo presses, dimensional checks, cycle-time tuning.
- **Robotic cells with 3D vision.** KUKA and COMAU cells with random bin picking and 3D sealant bead inspection.
